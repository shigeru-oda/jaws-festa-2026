## HTTP で行を引く（ダウンロード不要）

CKAN の DataStore が有効で、466 リソース（CSV 411 / XLSX 38 / XLS 17）が取り込み済み。ファイルを落とさずに行を引ける。

```sh
curl -sS 'https://ckan.pref.akita.lg.jp/api/3/action/datastore_search\
?resource_id=572d4724-0a72-4678-90c5-130d03573da6&limit=1'
```

ただし `datastore_search` は resource_id 1本ずつで、`datastore_search_sql` は無効（CVE-2026-42031 ほかにより既定で無効）。年次をまたぐ集計はカタログ側では書けない。
